HƯỚNG DẪN ĐẶT FILE SECURE CONNECT BUNDLE TẠI ĐÂY:
=====================================================

1. Đăng nhập vào DataStax Astra DB (https://astra.datastax.com/)
2. Chọn Database Cassandra của bạn (ví dụ: hotel_db)
3. Nhấp vào tab 'Connect' -> Tải xuống 'Secure Connect Bundle' (file .zip, ví dụ: secure-connect-hotel-db.zip)
4. Sao chép (copy) file .zip đó vào đúng thư mục này:
   d:\Code\NoSQL\Nhom9_UngDung_QLKS\astra-creds\secure-connect-hotel-db.zip
5. Cập nhật đường dẫn file và Token vào file src/main/resources/application.properties
